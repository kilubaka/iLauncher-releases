# iLauncher releases

Signed builds of [iLauncher](https://github.com/kilubaka/iLauncher), a minimalist, security-first Android launcher.

The source lives in the main repository. This repository only holds the downloadable versions, so the launcher (and you)
can find the newest one without needing access to the source.

## Install

1. Open the [latest release](https://github.com/kilubaka/iLauncher-releases/releases/latest) on your phone.
2. Download the `.apk` file and open it. Android will ask to allow installs from your browser or file manager, once.
3. Open iLauncher and, when asked, set it as your home app.

Requires Android 10 or newer.

## Updates

In iLauncher: **Settings → About → Check for updates** (off by default). When on, the launcher asks this repository for
the newest release name, at most every 12 hours, and shows "available" next to **Download latest version**. It never
downloads or installs anything by itself.

Each release is named by its version, for example `v0.1.75-alpha`.
